Dataset & source code details

Dataset details

Carparts-Seg: 3,833 images (train 3,156, val 401, test 276), 20,374 polygon annotations, 23 part classes, 640×640 images. 135 images have empty label files (quarantined in the Colab training copy only; originals untouched). Original Roboflow project (Gianmarco Russo, 2023) states CC BY 4.0; the curated 3,833-image set has no dataset licence stated — commercial rights are NOT confirmed. Academic use with attribution only. Cross-split pHash candidate pairs (191) are still unconfirmed — the test split is NOT claimed leakage-free.

Source code details

Training: colab/train_colab.ipynb (YOLOv8n-seg, 2-epoch smoke test, 25-epoch full run, validation, evaluation, Drive export). Inference: predict.py (standalone) and api/main.py (FastAPI). Full code, dataset sources and licence notes are in the GitHub repository (link below, added by the owner after publishing).
